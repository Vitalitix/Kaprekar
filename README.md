# Kaprekar's Constant Calculator

This web app calculates and displays the steps to reach Kaprekar's constant (6174) for a given four-digit number.

**Features:**

* Input a four-digit number.
* Input validation:
    * Ensures the input is a four-digit number.
    * Checks for at least two different digits in the input.
* Calculation of steps to reach Kaprekar's constant.
* Nicely formatted table to display the calculation steps, including:
    * Step number
    * Formula used in each step
    * Result of each step
